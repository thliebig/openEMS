#################
Python Tutorials
#################

Complete, runnable scripts, each demonstrating one kind of structure. Start
with the parallel plate waveguide: it is the shortest end-to-end simulation in
the set. The same tutorials exist for Matlab/Octave, see
:ref:`octave_tutorials`.

The scripts ship with openEMS in ``python/Tutorials/``.
